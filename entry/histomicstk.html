HistomicsTK Adopt

Python toolkit for digital pathology image analysis providing colour normalisation, nuclei detection and segmentation, feature extraction, and stain separation for H&E and IHC whole-slide images. Functions both as a standalone Python library and as a plugin for the Digital Slide Archive (DSA) web platform. Built on large_image for efficient multi-resolution image access. NIH-funded (U24-CA194362). Apache 2.0, 470 stars, 128 forks, v1.4.0 (February 2025). Maintained by Kitware and the DigitalSlideArchive organisation.
