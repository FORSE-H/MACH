Slideflow Adopt

Unified deep learning framework for digital pathology, providing a consistent API across weakly supervised, strongly supervised, multiple instance learning, and self-supervised training workflows on whole slide images. Handles slide processing, stain normalisation, patch extraction, model training, and deployment. Includes explainability tools (heatmaps, saliency maps) and an interactive visualisation interface (Slideflow Studio). Apache-2.0, 361 stars, v3.0.2 (October 2024).
