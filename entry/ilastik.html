ilastik Assess

Interactive machine learning toolkit for image segmentation, classification, object detection, counting, and tracking. Users interactively label a small number of image regions and ilastik trains a random forest classifier in real-time, applying predictions across the full image with immediate visual feedback. Supports 2D, 3D, and 4D images and handles large datasets efficiently through out-of-core processing. Workflows include pixel classification, multi-cut segmentation, object classification, cell tracking, and carving. Used across cell biology, neuroscience, and pathology for tasks where manual annotation is impractical at scale. Mixed GPL/LGPL, 398 stars, v1.4.2 (latest stable); v1.4.2rc1 (April 2026). Developed at EMBL Heidelberg and Janelia Research Campus.
