MARC v1 Assess

An open, configurable multi-agent framework for clinical AI reasoning: role-specialised LLM agents (extraction, reasoning, answer generation, evaluation) coordinate in a YAML-configured sequential pipeline that passes context explicitly and exposes traceable intermediate outputs, in place of a single monolithic prompt. Supports API-based (Gemini) and local CPU-compatible (Ollama) backends with per-agent RAG via Chroma; examples use the MedGemma medical model. The authors state it is a research framework, not a medical device, and not for clinical decision-making. Early-stage and lightly adopted.
