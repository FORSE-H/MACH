ClawBio Adopt

A bioinformatics-native AI agent skill library for the OpenClaw framework — each skill is a folder with a SKILL.md spec, Python code, demo data, and reproducibility outputs, read directly by a model-agnostic agent. Emphasises local-first, reproducible analysis (GWAS lookup, Galaxy bridge, variant workflows, reference-genome handling). MIT-licensed, community-driven, with skills accepted via pull request; individual skills may declare their own licences and depend on third-party tools/models with their own terms. Built on OpenClaw (the popular MIT open-source agent framework), so it needs a user-supplied LLM and API key to run.
