CliniCARE-Bench not scored

An open clinical-agent benchmark over MIMIC-IV from Scale AI. An agent answers a clinical question about a single patient record, accesses the chart through a governed tool surface, and returns a four-way verdict (YES, NO, INDETERMINATE for lack of data, or INDETERMINATE for medical ambiguity) with cited evidence. Scoring covers verdict accuracy, evidence retrieval, citation support, process-rubric adherence, and appropriate deferral when the record cannot settle the question. Comprises 25 scenarios / 750 tasks (150 indeterminate) plus a 148-case dev subset, with an evaluation pipeline, scenario templates, and a leaderboard. The MIT licence covers the code and scenario specs; patient data is NOT distributed — the MIMIC-IV-derived cohort bundle requires PhysioNet credentials and a DUA, and corpus documents carry per-publisher terms. Early-stage: the README states it is being prepared for public release.
