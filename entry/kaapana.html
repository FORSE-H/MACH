Kaapana Assess

Kubernetes-based open-source platform toolkit for building federated medical image analysis infrastructure. Orchestrates AI workflows (nnU-Net, TotalSegmentator), integrates MITK Workbench, 3D Slicer, and JupyterLab as plugins, provides an internal PACS (dcm4chee), object storage (MinIO), workflow engine (Apache Airflow), search (OpenSearch), and identity management (Keycloak). Designed for multi-centre federated learning — data stays on-site, only results are shared.
